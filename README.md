# Артпамять

Приложение на **Next.js 16 (App Router) и React 19** для подготовки к экзамену по истории искусства: **170 подписей и 129 изображений** из пользовательской коллекции. Работы без изображений остаются в каталоге и автоматически исключаются из тренировок.

## Открыть локально

Самый простой вариант: откройте **dist/art-memory.html** в Chrome или Safari. Сервер и интернет не нужны. Все 129 встроенных изображений находятся внутри этого HTML-файла. Его можно переносить отдельно. Основное Next.js-приложение запускается через `npm run dev` или `npm run start`. Автономный HTML — дополнительная версия тех же React-компонентов, собранная esbuild для открытия без сервера; она не содержит серверный runtime Next.js.

Уже собранную версию также можно открыть командой:

```sh
npm run local
```

Для разработки требуется Node.js 20.9 или новее:

```sh
npm install
npm run dev
```

Адрес: http://127.0.0.1:5173.

Производственный сервер Next.js запускается после сборки:

```sh
npm run build
npm run start
```
 Для проверки и сборки Next.js, а затем автономного HTML:

```sh
npm test
npm run build
npm run build:local
```

Локальная версия файла и версия сервера имеют разное хранилище браузера. Чтобы перенести прогресс между ними, используйте резервную копию.

## Возможности

- **Угадай картину**: отдельные поля для автора и названия, опечатки, перестановки соседних букв и порядок слов в названии, игнорирование «ё/е», регистра и пунктуации, явно заданные альтернативные ответы.
- В обычном/мягком режимах достаточно фамилии. Можно вводить полные имена, добавленные в варианты. Для нескольких авторов, перечисленных через «и», нужны все авторы.
- Известные похожие фамилии, например Мане и Моне, различаются: точное имя другого автора не засчитывается как опечатка.
- **Карточки**: вспомнить, перевернуть, самостоятельно отметить знание.
- **Интервальное повторение**: верные ответы возвращаются через 1, 3, 7, 14, 30 дней. Ошибки и подсказки сбрасывают серию и назначают повторение через 10 минут. Три верных ответа подряд дают статус «Помню».
- **Работа над ошибками**, новые работы, избранное, подборка по автору, любая коллекция без расписания.
- Тренировки по 10, 20, 30 работ или всей подборке; итог и повтор ошибок.
- **Каталог**: поиск, фильтры, плитки/список, просмотр и увеличение, редактор, личные ассоциации.
- Настраиваемая ежедневная цель, история 14 дней, точность без подсказок.
- Импорт изображений папкой или файлами, предварительная проверка CSV/TSV/JSON, экспорт и восстановление прогресса.
- Интерфейс для компьютера и телефона, клавиатура, диалоги с управлением фокусом, учёт настройки уменьшения анимаций.

Для работ, автор которых не указан в учебном списке, спрашивается только название. Атрибуции основаны на учебном списке пользователя, включая его трактовки; это не независимый искусствоведческий справочник. Очевидные ошибки распознавания исправлены. Исходная строка доступна в карточке работы, исходный файл — `public/list.txt`.

## Добавить оставшиеся изображения

В приложении: **Добавить картины → Выбрать папку**. Файлы должны называться `130.jpg`, `131.jpg` и т. д. Подписи для всех 170 работ уже готовы. Добавленные файлы сохраняются в IndexedDB текущего браузера.

Чтобы изображения вошли в исходники и будущую публикацию:

```sh
npm run import:collection -- /Users/ivanio/Documents/pic
npm run build
npm run build:local
```

Можно передать другим аргументом CSV/TSV/JSON со своими подписями. Нумерованный `list.txt` разбирается скриптом `scripts/prepare-list.py`, который содержит исправления исходного учебного списка.

## Формат подписей

CSV с разделителем `;` или табуляцией:

```csv
номер;автор;название
1;И. Шишкин;Рожь
```

JSON:

```json
[
  {
    "id": 1,
    "author": "И. Шишкин",
    "title": "Рожь",
    "authorAliases": ["Иван Шишкин"],
    "titleAliases": [],
    "note": "Личная ассоциация"
  }
]
```

Пример показывает формат, а не соответствие картины №1 исходной коллекции. В CSV варианты можно перечислять через `|` в колонках `authorAliases` и `titleAliases`.

## Хранение

Подписи, настройки, избранное и прогресс — localStorage. Импортированные изображения — IndexedDB. Встроенные изображения находятся в `public/paintings`.

Резервная копия JSON **не содержит импортированные изображения**: при переходе на другой компьютер отдельно импортируйте ту же папку. Очистка данных браузера удаляет локальный прогресс; регулярно скачивайте копию.

## Vercel и GitHub

Проект подготовлен для Vercel: framework Next.js, команда `npm run build`, стандартный выход `.next`. Публикация и создание GitHub-репозитория отложены по просьбе пользователя. После подключения GitHub импортируйте репозиторий в Vercel; секретов и внешней базы данных для этой версии не требуется.

## Структура Next.js

- `src/app/layout.jsx` — корневой layout, русский язык, метаданные, manifest и стили.
- `src/app/page.jsx` — главная страница App Router.
- `src/app/ArtMemoryClient.jsx` — браузерная граница: приложение читает localStorage только после загрузки клиента. Это предотвращает расхождение серверного HTML и сохранённого прогресса.
- `src/app/error.jsx` — обработка ошибок страницы.
- `src/App.jsx` и `src/components` — интерфейс и режимы обучения.

Формат и ключ хранилища `art-memory-v1` сохранены. Прогресс переносится автоматически при сохранении того же адреса браузера; между автономным файлом и сервером используйте экспорт/восстановление.

## Проверено

Автоматические проверки охватывают неточное сравнение ответов, различение похожих авторов, импорт с валидацией и планирование повторений. Производственная сборка и автономная сборка проходят. Проверка через браузер в среде выполнения была недоступна: запуск сервера запрещён, а встроенный браузер не открывает `file://`.
