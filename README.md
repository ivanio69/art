# артблять

Подготовка к экзамену по истории искусства: 170 работ, 140 подключённых изображений.

- Квиз: картина и четыре разных варианта с названием и автором.
- Экзамен: ввод автора и названия; проверка допускает опечатки и альтернативные названия. Если автор неизвестен, требуется только название.
- Галерея: вся коллекция, поиск по названию, автору и номеру, фильтр по автору и наличию изображения, крупный просмотр.
- Практика: 10, 20, 30 работ или вся подборка; все картины, умная подборка, ошибки или новые.
- Итог: результат, список ошибок и повтор только ошибочных ответов.
- Прогресс и настройки сохраняются в браузере. В настройках можно скачать копию прогресса.
- Незаконченный квиз или экзамен можно продолжить после обновления страницы, включая введённый текст и уже проверенный ответ.
- Прогресс квиза и экзамена учитывается отдельно. Прежний общий прогресс сохраняется как прогресс квиза.
- Избранное и сложные работы отмечаются в крупном просмотре галереи; обе подборки доступны для тренировок.
- Во время задания можно увеличить изображение. Клавиши 1–4 выбирают вариант в квизе, Enter после проверки открывает следующую работу.
- В настройках можно восстановить JSON-копию прогресса. Перед заменой автоматически скачивается копия текущих данных.
- «Экзамен без подсказок»: автор и название для всей подборки, оценка только в конце. Таймер 5–60 минут или без ограничения; его срок сохраняется при выходе и перезагрузке.
- До 100 завершённых занятий сохраняются с ответами, результатом и длительностью. При большой истории старые результаты удаляются, чтобы оставить место для прогресса; повтор ошибок доступен из каждого результата.
- Ежедневная подборка из 5–10 работ отдаёт приоритет незакреплённым ошибкам и повторению. Порядок стабилен в течение дня при неизменном прогрессе.
- Разбор ошибок отделяет автора, название, пропуски и путаницу между работами. В квиз возвращаются варианты, с которыми уже путали картину.
- Галерея листается стрелками и горизонтальным свайпом. Две работы можно выбрать для сравнения рядом.
- Опубликованный сайт можно добавить на экран телефона. В настройках — явное сохранение всей коллекции офлайн (~25 МБ); требуется HTTPS либо localhost и поддержка service worker. В режиме разработки используется автономный HTML.

## Запуск

Требуется Node.js 20.9 или новее.

```sh
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:5173.

```sh
npm test
npm run build
npm run start
```

## Автономная версия

```sh
npm run build:local
npm run local
```

Можно открыть `dist/art-memory.html` в Chrome или Safari. Все изображения включены в HTML, интернет не нужен. Файл и сервер используют разные хранилища браузера; прогресс можно переносить через экспорт и восстановление.

## Изображения

Положите файлы с номерами работ в `public/paintings`: например `156.jpg`. Поддерживаются JPG, JPEG, PNG и WebP. При запуске разработки и обеих сборках скрипт `sync-images.mjs` обновляет список изображений автоматически. После добавления файлов перезапустите разработку или пересоберите сайт.

Работы без изображения остаются в галерее, но не входят в квиз и экзамен. Пользовательского импорта и редактора на сайте нет.

Подписи и варианты ответов находятся в `src/lib/collection.json`. Атрибуции основаны на учебном списке пользователя.

## Хранение и публикация

Прогресс хранится под прежним ключом `art-memory-v1`; обновление сохраняет существующие данные. Очистка данных браузера удаляет локальный прогресс.

Next.js-приложение использует App Router и React 19. Изменения публикуются в существующий GitHub-репозиторий пользователя; отправка исходников сама по себе не подтверждает обновление хостинга.

Автоматической облачной синхронизации пока нет: нужен выбор хранилища и способа входа. Между устройствами прогресс переносится через JSON-копию, включая историю и разбор ошибок. Исторические периоды и направления не присвоены автоматически: учебный список содержит разные виды искусства и требует отдельной проверки атрибуций.
